# 🎓 Najot Ta'lim — O'quvchi va Admin Portali

Ushbu loyiha zamonaviy ta'lim markazining o'quvchi va boshqaruvchi (admin) tizimi sifatida **React**, **React Router v7** va **Tailwind CSS** yordamida yaratilgan.

## 🚀 Texnologiyalar

- **React 19**
- **React Router DOM v7** (`createBrowserRouter`, `ProtectedRoute`)
- **Tailwind CSS v4**
- **Vite**

## 🌟 Asosiy sahifalar va imkoniyatlar

- **O'quvchi kabineti (Student Panel):**
  - Bosh sahifa va ko'rsatkichlar tahlili
  - Mening guruhlarim va kurslar ro'yxati
  - Reyting va natijalar
  - To'lovlar tarixi va holati
  - Do'kon (Marketplace)
  - Sozlamalar va shaxsiy profil
- **Boshqaruv (Admin Panel):**
  - Himoyalangan yo'nalishlar (`ProtectedRoute`)
  - O'quvchilar va guruhlarni boshqarish

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
